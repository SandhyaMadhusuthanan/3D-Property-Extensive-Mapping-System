# Setup Guide

Follow these simple steps to access and run the **3D-Property-Extensive-Mapping-System** mockup locally on your machine.

## Prerequisites

Because this project is built as a fully client-side, self-contained static application (using HTML, CSS, vanilla JavaScript, and inline SVG), you do **not** need Node.js, databases, or complex backend servers. 

You only need:
- A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Apple Safari)
- [Git](https://git-scm.com/) (optional, if cloning via command line)

---

## Step-by-Step Instructions

Clone the project repository to your local computer, or download it as a ZIP file and extract it:
